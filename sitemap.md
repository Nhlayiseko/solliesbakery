## Page Relationships

| Page | Filename | Purpose |
|---|---|---|
| Home | `index.html` | Introduces Sollie's Bakery and highlights products and calls to action. |
| About Us | `about.html` | Provides the bakery history, mission, vision, values and team. |
| Products | `products.html` | Presents bread, pastries and celebration cakes with prices. |
| Gallery | `gallery.html` | Photographs of finished cakes and daily bakes. |
| Custom Orders | `enquiry.html` | Provides the custom-order enquiry form. |
| Contact | `contact.html` | Provides contact details, opening hours, locations and a general message form. |

## Navigation Flow

Every page contains links to:

- Products
